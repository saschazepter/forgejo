fix: make pagination mandatory on all APIs. The `page` and `limit` parameters to some Forgejo APIs have previously been optional, and if not provided have been interpreted as "retrieve all data". Forgejo will now default `page` to `1`, and default `limit` to `[api].DEFAULT_PAGING_NUM` (default: 30) on these APIs. For the affected list of APIs, please review https://codeberg.org/forgejo/forgejo/pulls/13960.
